# 🎓 IRKOP Belajar TK

## 🌟 Bermain Sambil Belajar untuk Anak

**IRKOP Belajar TK** adalah aplikasi edukasi interaktif untuk anak-anak yang menggabungkan pembelajaran dan permainan dengan tampilan yang ceria, penuh warna, serta mudah digunakan oleh anak usia dini.

Aplikasi dirancang agar anak dapat **belajar sambil bermain**, mengenal berbagai materi dasar melalui visual, suara, mini game, kuis, mewarnai, dan permainan interaktif.

---

# 🏠 Fitur Utama

## 🔤 Dunia Huruf

Belajar mengenal huruf alfabet dari **A sampai Z**.

### Fitur

- Huruf A–Z lengkap
- Visual gambar pendukung
- Nama huruf
- Contoh kata
- Audio pengucapan
- Tombol dengarkan suara
- Navigasi materi
- Tab Belajar
- Tab Mini Game
- Pertanyaan interaktif

### Contoh

> A → Apel 🍎

> C → Cicak 🦎

## 🔗 Titik & Garis

Permainan belajar dengan cara menghubungkan titik secara berurutan.

### Cara Bermain

Anak harus menarik garis mengikuti urutan nomor pada titik.

### Fitur

- Titik bernomor
- Sistem urutan
- Tarik garis
- Beberapa level gambar
- Audio instruksi
- Audio saat berhasil
- Gambar asli muncul setelah selesai

### Level

- ⭐ Bintang
- 🏠 Rumah
- 🐟 Ikan
- 🌸 Bunga
- 🚗 Mobil

Setelah semua titik berhasil dihubungkan, anak akan melihat hasil gambar sebenarnya.
