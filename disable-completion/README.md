# Belajar TK — Bermain Sambil Belajar (IRKOP)

Aplikasi web edukasi anak TK: Huruf ABC, Angka 1-10, Hijaiyah, Gambar,
Warna (latar ikut berubah), Mewarnai, dan Kuis.

- Narasi Bahasa Indonesia: Web Speech API (`id-ID`)
- Efek suara + musik latar: Web Audio API (tanpa file audio)
- Murni statis, siap deploy ke GitHub Pages
